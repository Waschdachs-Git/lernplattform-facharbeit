Was macht diese Website?

Die App zeigt einen Lernpfad mit Modulen. In jedem Modul gibt es Levels, die in drei Phasen gelöst werden. Am Ende entsteht eine kleine eigene Website.

1

Roadmap & Reihenfolge

Der Lernpfad führt von HTML über CSS zu JavaScript. Module werden passend zum Fortschritt freigeschaltet.

2

3-Phasen-Modell

Jedes Level besteht aus Theorie, einem kurzen Check und einer Sandbox. Dadurch bleibt der Einstieg einfach und übersichtlich.

3

Sandbox & Vorschau

Code wird direkt ausprobiert: HTML/CSS mit Vorschau im iframe, JavaScript mit Konsole und interaktiven Elementen.

4

Fortschritt speichern

Der Lernstand wird lokal im Browser gespeichert (localStorage). So bleibt alles auch nach dem Schließen erhalten.
